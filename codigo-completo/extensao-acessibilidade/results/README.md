# Resultados

Armazene aqui os arquivos CSV exportados pelo laboratório, com nomes descritivos e data de coleta. O navegador normalmente salva downloads em sua pasta Downloads: mova o CSV para esta pasta manualmente.

A saída de exemplo `metricas-ava-experimento.csv` contém indicadores heurísticos e medições por quadro. Para métricas de classificação (precisão, revocação e F1-score), crie uma tabela de rótulos de referência independente; não use o indicador produzido pelo algoritmo como rótulo verdadeiro.
